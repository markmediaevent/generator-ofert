FINALNA POPRAWKA

Najważniejszy naprawiony błąd: przy wczytywaniu oferty aplikacja próbowała najpierw połączyć się z GitHub. Gdy token GitHub był błędny lub wygasł, serwer zwracał „Bad credentials”, mimo że oferta istniała lokalnie. Teraz oferta jest zawsze wczytywana najpierw z lokalnego/trwałego dysku, a awaria GitHub nie blokuje działania.

Render:
Build Command: npm ci --omit=dev --no-audit --no-fund
Start Command: npm start
Health Check Path: /api/health
Environment: STORAGE_DIR=/var/data
Persistent Disk mount path: /var/data

Po wdrożeniu sprawdź /api/health. storageDir musi wynosić /var/data.
